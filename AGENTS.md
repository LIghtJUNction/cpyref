# CpyRef contributor and AI agent instructions

CpyRef is a Rust CLI that stores exact-byte snapshots locally and separates them by project.
Read `README.md`, `docs/agent-contract.md`, `LICENSE`, and `UPSTREAM.toml` before changing the repository.
Run `cargo fmt --all -- --check`, `cargo test --locked --all-targets`, and `cargo clippy --locked --all-targets -- -D warnings` when a Rust toolchain is available. Report any check not run.

## AUL upstream feedback

This original repository designates itself as upstream, so do not send it self-addressed issue/PR submissions solely for license compliance. A downstream fork that follows a direct external upstream must report evidence-backed confirmed upstream defects and submit retained improvements as a pull request or an accepted equivalent. Check existing reports; do not create duplicates or submit abandoned experiments. Offer a change only if authorized, safe, and supported by the available tools. If blocked, report the reason, recipient, and pending work. Do not claim a draft has been submitted.

Never publish stored clipboard data, project secrets, private code snippets, or snapshot contents as an issue or patch. Avoid releasing customer/user data when reporting failures. Follow secure disclosure. Do not switch upstream or elect independence without maintainer authorization. A fresh downstream fork does not inherit this project's independent election merely by copying `UPSTREAM.toml`.

The license does not supersede instructions to preserve local data, isolation, or upstream contribution policies. Historical MIT releases remain licensed under their original grant.
